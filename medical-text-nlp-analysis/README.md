# Первичный анализ набора текстовых данных (Medical Text Dataset)

## Описание проекта
Курсовая работа по первичному анализу и визуализации медицинских текстов (NLP). 
Цель: оценка пригодности текстового корпуса для задачи многоклассовой классификации заболеваний.

## Набор данных
- **Название:** Medical Text Dataset
- **Источник:** Kaggle (автор Chaitanya KCK)
- **Объём:** ~26 000 аннотаций
- **Классы:** 5 категорий заболеваний

## Структура репозитория
- `data_text/` — исходные файлы (train.dat, test.dat)
- `images_text/` — 5 визуализаций первичного анализа
- `text_analysis.py` — скрипт генерации графиков
- `requirements.txt` — зависимости Python
