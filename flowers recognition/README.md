# Анализ набора данных с изображениями: Роза vs Подсолнух

## Описание
Первичный анализ датасета **Flowers Recognition** (бинарная подвыборка: розы и подсолнухи) в рамках курсового проекта по дисциплине «Введение в проектную деятельность».

## Датасет
- Название: Flowers Recognition (бинарная подвыборка)
- Источник: Kaggle / alxmamaev
- URL: https://www.kaggle.com/datasets/alxmamaev/flowers-recognition
- Лицензия: CC0 (открытое использование)
- Размер: 1 518 изображений (784 розы + 734 подсолнуха)
- Тип задачи: Бинарная классификация изображений

## Структура репозитория
data_text/ — исходные файлы (train.dat, test.dat)
images_text/ — 5 визуализаций первичного анализа
text_analysis.py — скрипт генерации графиков
requirements.txt — зависимости Python
